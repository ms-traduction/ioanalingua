IORANA — page d'accueil (première version)
===========================================

Fichiers :
- index.html : contenu de la page
- style.css  : couleurs, typographies et mise en page responsive
- script.js  : menu mobile et année du pied de page
- logo.webp : logo officiel de la marque
- globemain.webp : image locale de la section d'accueil

Pour prévisualiser :
1. Décompressez le ZIP.
2. Ouvrez index.html dans votre navigateur.
3. Une connexion Internet est nécessaire pour charger Google Fonts.

Avant publication :
- Remplacez bonjour@iorana.example par votre véritable adresse professionnelle.
- Les liens EN et ES sont des éléments visuels provisoires : les pages traduites ne sont pas encore créées.
- Le logo officiel et l'image du globe sont utilisés directement depuis les fichiers locaux du projet.
- Remplacez dans index.html les valeurs entre crochets par votre adresse e-mail, votre numéro WhatsApp et les URL de vos pages légales.
- Les sections Contact et FAQ existantes sont liées directement. Aucun système de consentement ou de configuration des cookies n'est présent dans cette version.

Publication sur Netlify :
Déposez le dossier décompressé dans Netlify Drop, ou importez-le dans un dépôt GitHub et connectez ce dépôt à Netlify.
